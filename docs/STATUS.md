# 开发状态

2026-11-09，1.3 开发版。

源码可构建，包含当前雨夜城市、弯道高架、车流、玻璃雨水和科幻电驱音效。近期已做功能和实际画面检查；本次公开提交尚未完成最终 10 分钟连续驾驶验收，不把旧版测试结果作为本提交的验收证明。最终运行包和演示视频稍后单独交付。

当前已知限制：

- 电驱选项改变音效，车辆仍使用相同的六挡动力模型。
- 轿车使用一个详细基础车模；地铁与玩家座舱仍是自建几何。
- 东京城市块由航空测量数据重排，近看立面精度有限，场景不复现真实道路。
- 水滴、拖尾和气流采用屏幕空间近似；湿路反射在坡道和上下层有平面近似误差。
- 第二层高架为景观，尚不能驶入匝道。

本仓库不包含本机启动记录、账户信息、临时研究文件或旧版验收报告。
